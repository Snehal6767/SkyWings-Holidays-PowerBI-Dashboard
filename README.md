# ✈️ SkyWings Holidays – Aviation & Revenue Analytics Dashboard

## 📌 Project Overview
An executive-grade Power BI dashboard built for **SkyWings Holidays** to analyze commercial aviation performance, booking volumes, and package holiday attach rates. The goal of this project was to transform raw travel booking data into actionable commercial insights and identify upsell opportunities.

## 🛠️ Tech Stack & Tools
* **Power BI Desktop:** Data modeling, interactive UI design, and visualization.
* **Power Query:** Data cleaning, type transformation, and shaping.
* **DAX (Data Analysis Expressions):** Custom measures including revenue calculations, package booking counts, and dynamic attach rate percentages.

---

## 📈 Key Metrics & Features
* **Total Revenue & Total Bookings:** High-level executive KPI tracking.
* **Package Attach Rate %:** Measures the conversion success of bundling flights with holiday packages.
* **Interactive Slicers:** Dynamic airport base filtering (`Departure_Base`) for localized route analysis.
* **Visual Breakdown:** Clustered column charts for destination revenue and donut charts for customer segment distribution.
